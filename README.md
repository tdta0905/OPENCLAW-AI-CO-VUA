## ✨ Project Features

- ♟️ **Chess Board:** Giao diện bàn cờ vua trực quan.
- 🤖 **AI Opponent:** Định hướng xây dựng đối thủ máy.
- 📜 **Move History:** Theo dõi lịch sử các nước đi.
- ↩️ **Undo Move:** Quay lại nước đi trước.
- 🔍 **Move Analysis:** Định hướng phân tích và gợi ý nước đi.
- 🧩 **OpenClaw Integration:** Hướng phát triển kết nối trợ lý AI với kỹ năng chơi cờ.
- 📱 **Responsive UI:** Hướng đến trải nghiệm trên cả máy tính và điện thoại.

*Các tính năng cần được đối chiếu với phiên bản demo thực tế; một số mục là định hướng phát triển, chưa phải tính năng AI đã hoàn thiện.*

## 🧠 How It Works

Dự án hướng đến mô hình hoạt động gồm các thành phần:

```text
Player
  │
  ▼
Chess Web Interface
  │
  ▼
Chess Rules & Game State
  │
  ▼
AI Decision Engine
  │
  ▼
Move Suggestion / Explanation
  │
  ▼
OpenClaw Integration (Future)
```

- **Frontend:** Hiển thị bàn cờ và nhận thao tác người chơi.
- **Chess Logic:** Kiểm tra nước đi và trạng thái ván cờ.
- **AI Engine:** Chọn hoặc đánh giá nước đi.
- **OpenClaw:** Định hướng tích hợp kỹ năng để giải thích chiến thuật và hỗ trợ người chơi.
